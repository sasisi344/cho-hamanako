# サヨリ（浜名湖）— 時期・サイズ・釣り方の確定事項

> 2026-10-05 オーナー確認。サヨリ記事（`sayori` / `large-sayori-guide` / `april-guide` / `sayori-boat-guide` / `sayori-beginner-guide` / `urayasu-choho` / `sayori-cooking` / `sayori-fukabori`）はこの内容に揃える。

## 時期（陸っぱり基準）

| 時期 | 状況 |
|---|---|
| 基本 | **夏〜秋が本番。基本は秋で、10月がメイン** |
| 8〜10月 | 数釣りの最盛期 |
| 9月（初秋） | 数釣り＋大型（30cm級）も交じる年。もっとも期待できる入口 |
| 10月前後 | **特に狙い目**。群れが安定し、30cm級の報告も増える |
| 10月以降〜冬 | 30cm級の釣果報告あり。サイズ狙いは冬だが、**陸っぱりからは難しい → ボート推奨** |
| 春（4月） | 大型も入るが、陸っぱりからは釣りにくい。記事の主軸にはしない |

## 書き方のルール

- 「サヨリ＝春（4月）の釣り」「4月・9月がチャンス」とは書かない。主軸は **9月の初秋〜10月前後**。
- 大型・冬のサイズ狙いは「陸からは難しい／ボート推奨」を必ず添える。
- 10月前後が狙い目である**理由として「産卵のために沿岸へ寄る」とは書かない**（下記の未確認事項）。理由は「適水温（12〜20℃）で沿岸浅場へ接岸」「今切口から大きな群れが入る」「陸から届く範囲に群れが回る」で説明する。

## 生態・習性（記事で使ってよい内容）

- 表層（水面直下〜50cm）を泳ぐ回遊魚。数百〜数千匹の群れで行動する。
- 適水温12〜20℃で沿岸の浅場へ接岸。外洋から今切口を通って湖内へ入る。
- 警戒心が強く、大型ほど岸壁の近くを避けて沖の潮目に溜まる。
- 上げ潮の動き出しが時合。風上→風下へ移動する傾向。
- 食性はアミエビ等のプランクトン類。コマセで足止めできる。

## 釣法

- ウキカゴ（待つ釣り）: コマセを撒き、群れが回ってくるのを待つ。
- 浦安釣法（攻める釣り）: 遠投してデッドスローで巻き、沖の群れを探して追わせる。力糸PE2〜3号を8〜10m、先糸は長め。アタリで合わせず巻き続けて追い食いを待つ（出典: 工房浦安の解説記事）。
- 冬の大型はボートで群れを追う（`sayori-boat-guide`）。
