# 浜名湖リサーチデータ：マダコ（通年）

> 最終更新: 2026-08-17 / Agent-A シーズンリサーチにより§5〜§8を追加

## 1. 現在の生態ステータスと活性
- **ステータス:** **「接岸・成長期」**。
- **活性:** 5月下旬〜8月。産卵を控えた個体や成長途中の個体が浅場へ集結。
- **特徴:** 全国でも有数のタコ釣りポイント。6月の数釣りと8月の型狙いが楽しめる。

## 2. 適水温と魚の居場所の推移
- **適水温:** 20℃〜25℃（釣り最適）。生態上の活動域は15〜25℃。
- **居場所:** 砂地と岩礁・敷石が混在するエリア。壁際や基礎。
- **主要ポイント:** 砂揚げ場、新居海釣り公園、網干場、六角堂周辺。

## 3. メインベイト（捕食対象）と集まる条件
- **甲殻類（カニ・エビ）:** タコの主食。
- **貝類:** アサリやカキ。
- **集まる条件:** 砂地でかつ餌（カキ棚や石組み）が豊富なエリア。

## 4. 最も有効なアプローチ
- **タコエギ:** エギングの要領で底を叩いて誘う。
- **タコテンヤ:** カニやアジをエサにする。
- **コツ:** 浜名湖の速い潮で底が取れない時は、30号以上のオモリを足してでも底を確保すること。

## 7. シーズン断定（データ根拠）

### 断定: **浜名湖マダコの平年シーズンは5月下旬〜9月末**

- **コアシーズン（数・型ともに狙える）**: 6月〜8月
- **数釣り特化**: 7月〜9月（特に7月最盛期）
- **大型狙い特化**: 5月下旬〜6月初旬・11〜12月（産卵前大型、難易度高）

### ユーザー体感「4〜9月がベスト」の検証
- **4月**: 複数ソースで実績報告なし。活性低いと明記。ほぼ釣果なし。
- **5月**: イシグロで5月18日弁天島の釣果あり（コブシサイズ）。スズキマリンも5〜7月をメインシーズンとする。5月中旬以降は現実的。
- **9月**: 新子シーズン。複数ソースで確認。ユーザー体感と一致。
- **断定修正案**: 「**5月中旬〜9月末**」が実績ベースの平年シーズン。「4〜9月」のうち4月は大幅に釣果が下がる。

## 9. 高水温と気温：天気予報活用の実践知識（2026-08-17追記）

### マダコの高水温耐性
- **生存限界**: 30℃程度（海釣りのバイブル）
- **適水温**: 15〜25℃、最適20℃前後
- **26〜28℃**: 活性は落ちるが釣果は出る。苦潮リスク始まる
- **苦潮（低酸素）**: 高水温で海中の酸素が減少した状態。タコが岸壁に浮き上がっていたら苦潮のサイン（活性ゼロ）

### 表浜名湖の水温特性
- 太平洋からの海水循環が直接入るため、28℃超になることは稀（ユーザー現地知識）
- 奥浜名湖（内陸部浅場）は夏に29〜30℃に達することがある → タコポイントとしては表浜有利
- 参考データ: hama-angler.com掲載の月別水温（7月中旬〜8月上旬: 25〜28℃、8月中旬〜下旬: 27〜29℃）

### 気温トレンドから水温を推測する目安
| 気温状況 | 表浜名湖の推定水温 | 釣れやすさ |
|---------|-----------------|----------|
| 梅雨期の曇り・雨続き（気温25〜28℃） | 20〜23℃ | ◎（陸っぱり最良） |
| 晴天継続（気温30〜33℃） | 22〜26℃ | ◎（全時間帯） |
| 猛暑日続き（気温35℃超×3日以上） | 26〜28℃ | 〇（朝マズメ集中） |
| 台風通過後1〜3日 | 一時的に低下 | ◎（水温撹拌で適正帯に） |
| 秋の気温低下（気温28℃以下） | 25℃以下に低下 | 〇→△（深場移動開始） |

### 水温27℃超 = 深場シフト法則（記事執筆時の重要メソッド）
- 表層水温27℃超でタコは水深5m以深へ移動
- 夏の浜名湖では表層と水深5m以深で2〜5℃の温度差が発生
- 天気予報での判断: 気温35℃超×3日以上 → 表浜でも27℃近い可能性 → ボート優先
- 陸っぱり代替策: 朝マズメ（4〜6時）限定 + 重いタコエギで遠投沖目狙い
