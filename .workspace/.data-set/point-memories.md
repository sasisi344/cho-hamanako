# ポイント別の思い出メモ（筆者記入）

ポイント記事（`category: points`）に「思い出」として入れてよい釣行のエピソードの置き場。**筆者（さしし）だけが記入する。** AI はここにあるものだけを使い、追記・創作はしない（[writing-style/SKILL.md](../../.agents/writing-style/SKILL.md)「記事の体温」）。

## 書き方

- 見出しはポイント記事の `slug`
- 1項目1行。いつ頃（季節・年代でよい）／何をした・何が起きた／そのとき思ったこと
- 釣果の数字は覚えている範囲で。あいまいなら「たしか」と書いておく（記事ではぼかして使う）

## 記入例

```
## gardenpark
- 春（数年前）／夕マヅメに足元でキビレが連発した／潮が動き出す30分が勝負だと実感した
```
