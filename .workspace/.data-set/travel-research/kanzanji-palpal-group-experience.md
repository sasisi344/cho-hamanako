## 1. 舘山寺温泉エリアの観光需要（現状）

### 需要の実態

| 項目 | 内容 |
|------|------|
| 位置づけ | 浜松市最大・西静岡最大の温泉地 |
| 主要コンテンツ | 温泉旅館・パルパル遊園地・湖クルーズ・ロープウェイ・フラワーパーク・動物園 |
| 主要ターゲット | ファミリー・カップル・グループ旅行 |
| インバウンド対応 | たきや漁で英語通訳ガイドあり（iN HAMAMATSU 掲載）|
| 2025年動向 | 温泉協会が「2025〜2026秋冬グループお泊り宴会プラン」を積極プロモーション |

### 観光地としての強み

- **複合型リゾートの構造**: 温泉 + 遊園地 + 湖アクティビティ + グルメ（うなぎ・牡蠣・とらふぐ）が1エリアに集中
- **ロープウェイ**: 湖上空から浜名湖を一望。インスタ映えポイントとして有効
- **SUP・遊覧船**: 湖面アクティビティの整備が進んでいる
- **ホテルウェルシーズン浜名湖**: パルパルに直結。遊園地 + 温泉スパ + 宿泊が一体

### 国内旅行需要

インバウンド全体では2025年の外国人宿泊数が過去最高水準（地方部は前年比+19.1%）。  
浜松・浜名湖エリアも地方型観光地として需要回復・成長基調にある。  
温泉地としての認知は依然として高い（ゆこゆこ・じゃらん・楽天トラベルいずれも多数掲載）。

### 課題認識

- 個人旅行者向けのパッケージ（ツアー商品）は少なく、FIT（自由旅行）が主流
- バスツアーとしての造成は減少傾向（ユーザー言及通り）
- 「温泉 + α」の体験コンテンツが競合との差別化になる

## 2. 浜名湖パルパル × ファミリー × 釣り連動の可能性

### パルパル基本情報

| 項目 | 内容 |
|------|------|
| 所在地 | 静岡県浜松市中央区舘山寺町1891（舘山寺温泉エリア内） |
| コンセプト | 「ファミリーにちょうどいい遊園地」 |

| 区分 | 0〜2歳 / 3〜6歳 / 小学生 / 中高大学生 / 法人利用 を明示 |
| パルプール | 湖面と一体化した流れるプール・子どもプールあり |
| 料金改定 | 2025年4月1日より一部値上げ |

### 釣りとの連動シナリオ（提案）

**直接連動は難しい理由:**
- パルパル自体に釣り体験コンテンツなし
- 遊園地→釣り場の移動が発生する（車で数分〜15分）

**現実的な連動プラン（コンテンツ設計案）:**

| プラン名 | 流れ | 釣りの位置 |
|---------|------|-----------|
| **午前パルパル→午後ファミリーフィッシング** | 10:00パルパル入場→13:00退場→14:00弁天島or渚園でちょい投げ | ご褒美感を維持しつつ釣りデビューへ |
| **温泉チェックイン→翌朝早朝釣り** | パルパル1日→舘山寺温泉宿泊→翌朝6:00舘山寺護岸 | 親は釣り目的、子どもは温泉・遊園地目的でWin-Win |
| **パルパル → 舘山寺護岸の延べ竿釣り** | パルパル退場後、徒歩圏内の舘山寺護岸で延べ竿ハゼ釣り（夕方向き） | 移動ゼロに近い最も現実的な接続 |

### 釣りコンテンツの設計ポイント

- **ターゲット**: 子どもに「ご褒美」として遊んだ後に釣りを提案できる
- **舘山寺護岸**: パルパルから徒歩圏内、延べ竿でハゼ狙い可（夕方向き）。メバルは不可
- **渚園**: 車で数分。キャンプ場でBBQまで繋げられるので「1泊2日ファミリー旅」に組み込みやすい
- **関連記事候補**: `travel/hamanako-camp-fishing`・`travel/golden-week-family-sabiki-debut`にパルパルへの言及を追加する価値あり

#### 団体割引・特別プランの有無（2026年9月調査）

**公式サイト・観光情報サイト上に団体割引・法人向け特別プランの記載なし。**

料金設定は「通常期 / 繁忙期」の2段階のみで、グループ割引の明示はされていない。  
大人数（10名超）の場合は複数隻チャーターを組み合わせるが、隻数が増えても単価は変わらない構造。  
特別な条件や大型団体の相談は電話（090-8910-8075）直接問い合わせが必要。

**コンテンツ設計上の示唆:**  
「団体割引はないが、複数隻まとめ予約で一体感のある体験が作れる」「割引より体験の希少性・宴会付き・SNS映えで訴求する」が正しい方向性。料金をおとりにするより**非代替性**（浜名湖でしかできない）と**宿泊接続の自然さ**で押す。

### 団体・慰安会需要の評価

**強み（社員旅行・友人グループに向く理由）:**

1. **非日常体験の完結性**: 漁→宴会（筏での食事・飲酒）→宿泊が1セットで完結
2. **SNS映え要素が高い**:
   - 夜の湖面が黄緑色に光る幻想的な景観
   - 獲れたてのエビ・カニを料理する映像
   - 筏での宴会・乾杯シーン
   - 普段体験できない「漁師体験」感
3. **競争力**: 全国的にほぼここだけ（えびすき漁は特に）→「行ったことない体験」として共有しやすい
4. **宿泊接続が自然**: 夜間体験なので宿泊は必須に近く、CVが取りやすい
5. **飲酒可能**: たきや漁後の筏宴会はアルコール提供あり（花の舞酒造スパークリング日本酒の提供確認）

**制約・注意点:**

| 制約 | 内容 |
|------|------|
| 1隻あたり4名上限（たきや漁） | 大人数の場合は複数隻必要。船頭の数が上限になる |
| 大人数の予約 | 「団体予約が好まれる」ユーザー認識通り、事前相談が必要 |
| シーズン限定 | 5月〜9月のみ。社員旅行の時期を合わせる必要あり |
| 天候依存 | 雨天・荒天時は中止の場合あり |
| 予約競争 | 人気が高く、受付開始直後に埋まる（2026年は5月5日開始） |

### コンテンツ設計への示唆

- **友人グループ（4〜8名）**: たきや漁1〜2隻 + 帰漁後たきや亭で宴会 → 弁天島のホテル宿泊 が最もスムーズ
- **社員慰安会（10名超）**: 事前に運営者へ直接相談が必須。複数隻チャーターは対応可能だが要確認
- **記事での訴求方針**: 「夜の浜名湖でしかできないことがある」「SNS映えすること保証」「翌日は釣りで締める」という流れで、宿泊アフィリエイト（rakuten-travel-stay）に自然につなげる
