**前提**: Points記事は「情報提供・意思決定支援」。Tactics記事は「方法論・確実性向上 → TackleCard」。

## 共通ルール

- **TackleCard**: 実績・確実性の根拠が書けるものに限定。「浜名湖でこれが効いた理由」を1行書いてから置く
- **BlogCard**: 実在slug確認必須（`src/content/blog/`）
- **断定回避**: ボートレンタル料金・SUP禁止区域・漁業権エリアは「要公式確認」誘導
- **法令必須**: ボート・ウェーディング系は `fishing-laws-hamanako.md` を参照して安全・法令セクションを入れる
- **文字数目安**: 3,000字+（tactics はサイト内最大級の深度ティア）
- **GMapButton**: tactics記事には置かない（ポイント記事側に置く）

### セクションごとの執筆指示

**H2: 猪鼻湖は「知る人ぞ知る」エリアである理由**  
→ 奥浜名湖の最奥部であり、アクセスの難しさゆえに釣り人プレッシャーが低いことを書く。水の流れが弱く水質が異なるため、クロダイ・シーバス・ウナギが溜まりやすい環境であることを地形から説明する。「知っている人だけが恩恵を受けられる」という秘境感を出す。

> [!forAI]
> アクセスは自動車メインになるので電車は難しい。猪鼻湖の周囲は釣りができる箇所が限定されているし競争率が高いのも一部だから、浜名湖内では穴場といえる。ウナギは居ないことはないけど釣り対象にするべきではない、むしろ美味しい・有名なウナギ屋はあるのでそっちがメインにするほう。

**H2: シーズン別ターゲット早見表**  
→ 表形式で月×魚種を整理。春クロダイ（乗っ込み）/ 夏シーバス・ウナギ / 秋クロダイ・シーバス / 冬は厳しい、という流れ。釣れない時期も正直に書くことで信頼を得る。

> 概ね合っている。ウナギは釣れる対象から外すべき。冬は厳しいけれど水深がある瀬戸水道の北側ならチャンスはあるしカレイの実績はある、遠投できるなら陸からでも可能。水深があるエリアは猪鼻湖の地図でいうなら南側（瀬戸水道）から東部になる。これは国土地理院の水深図などを見るとわかりやすい。

**H3: ショア（陸っぱり）で狙えるポイントと限界**  
→ 護岸や干潟の際からチニング・ウキ釣りで狙える場所を示す。ただし奥地の好ポイントには届かないことを正直に書き、次のH3への自然な流れを作る。「ショアでできること・できないこと」を区別することで読者が自分のスタイルを選択できるようにする。

> 護岸でやるなら三ヶ日駅付近でウキ釣り、夏から秋にかけてはいろいろ狙える。大型狙いなら南部と東部で投げ釣り。夏から秋にかけての高水温ならウキ釣りでもいいけど、春と晩秋の適正水温から下になりかけている時は、80mくらい投げれる投げ釣りで、広範囲を探るのがベスト。

**H3: ウェーディングで広がる世界**  
→ 浅いシャロー帯（干潮時の干潟エリア）にウェーダーで入ることでクロダイのテリトリーに近づける、という具体的な優位性を書く。どのエリアがウェーディングに向くか（参考情報として、断定なし）。ライフジャケット着用必須・足元注意（急深）を先に書いてから釣り方に入る。

> ウェーディングに向いているのはリゾートホテルがある西部。砂場と砂礫があったりボトムをひきずるやり方もできるが、根本的な問題として、駐車場がない場所が多い。ホテルに宿泊してその敷地内でやるにしても許可取りは必要になるかもしれない。

**H3: SUPフィッシングが真価を発揮する理由**  
→ 陸から届かない猪鼻湖中央部・細江上流方向へのアクセスができる点を強調。音が静かで魚を驚かせない点も。`method-kayaking-intro` への BlogCard を置き、入門知識はそちらへ誘導する。SUP禁止区域・ライフジャケット義務については断定回避・公式確認を促す。

> SUPやカヤックもエントリーしやすい場所はある。猪鼻湖の南部から東部の地図でいうなら右半分は水深もあり潮流もタイミング次第で強くなるのでカヤックでも注意したほうがいい。このエリアはとくに夏から秋にかけてはマリンスポーツとかジェットスキーが多くなるので、カヤックなど洋上ですぐ動けないとか目立たない存在は特に注意するべき。カヤックは標識の旗が必須ではあるけど、問題はSUPで立っていないと他人から視認しずらいことを理解する。ジェットスキーは速度もあるししょうじきまともに目を開けていられないので、トラブルや事故に巻き込まれる可能性は考えつつ行動をすること。

**H2: 確実に仕留めるためのタックル選択**  
→ TackleCard を置く箇所。想定アイテム: ウェーダー・ライフジャケット（安全装備）/ チヌ用フロロライン / チニング用ロッド / 実績ルアー（チヌトップ or ボトム）。各アイテムに「なぜ猪鼻湖で有効か」の1行根拠を付けてから置く。

> おすすめタックルについては、出来る釣りの方法によりおすすめが変化する。カヤック＆SUPは専用記事へリンクを貼ればいい。ここのターゲットはクロダイ・キビレ・シーバスあたりで、時期によってカレイ（投げ釣り）がメイン。クロダイ・キビレ・シーバスは同じ釣り方でも釣れるんだけどルアーでは時間帯とルアーのタイプとレンジが変わることに留意。

**H2: 猪鼻湖エリアのおすすめポイント**  
→ BlogCard: `kanzanji`（舘山寺・内浦湾） / `sunza`（寸座） / `syounaiko`（庄内湖） / `method-kayaking-intro`（SUP・カヤック入門）

**H2: ⚠️ 安全・ルール**  
→ 猪鼻湖の急深箇所・ウェーディング中の転倒リスク / ライフジャケット着用義務 / 漁業権エリア（ fishing-laws-hamanako.md 参照）を簡潔に。「楽しむために必ず確認してほしい」トーンで。

### セクションごとの執筆指示

**H2: 内浦湾はどんなエリアか**  
→ 舘山寺温泉・観覧車・遊覧船があるレジャーエリアであることを最初に触れ、「そのすぐ近くに実は超一級釣り場がある」という意外性を打ち出す。閉鎖性水域（湾奥）で水が緩く、常夜灯が多いため昼夜問わず魚が付きやすい地形であることを説明。

> 常夜灯・街灯は多くない。場所によってごく一部にあるけど、釣りに直結する理由としては「ライトがいらないくらい」のメリットで、常夜灯があるからそこに魚が集まるってわけでもない。理由としては、ベイストリート側はホテルの照明とか灯りがあるのでこれを常夜灯と呼べるかどうか。パルパル側は九重というホテルが解体されてから釣り場が広くなった感じではあるけど、ストラクチャーが減ったのと水深が浅めになっている。舘山寺山と大草山のふもとは釣りをすることもできるけど、山をのぼる必要があるので競争率は低いし背後が狭いのでぶん投げる釣りには向いてない。

**H2: あなたはどちらのタイプ？**  
→ シンプルな2択ボックスを作る。「家族・観光ついでにライトに釣りしたい → 昼の釣りへ」「夜に本気で大型を狙いたい → ナイトゲームへ」。読者が自分に合ったセクションに飛べるようにする（見出しでアンカーが生まれる）。

> この2択はどちらも狙えるけど、ライトな釣りならパルパル側とベイストリート、大型狙いなら山のほうが向いているが、日中に下見をしておくべきで、その理由は急深になっていることと時期によっては道にスズメバチの巣があったりするしヤブを通ることもあるから。

**H3: 狙いやすいポイントと釣り方（昼）**  
→ 護岸・桟橋周辺で手軽に狙えるクロダイ・キビレ・ハゼ・サヨリを紹介。子供でも楽しめるサビキ・ウキ釣りから、少し上を狙うちょい投げまで。「観光の半日を使ってサクッと楽しむ」イメージで書く。

**H3: ファミリー向けタックルセット**  
→ TackleCard: 入門向けコンパクトロッド+リールセット、サビキ仕掛けなど。「釣具屋に行く時間がない人向け」として提案。

**H3: 夜に爆発する理由**  
→ 常夜灯・明暗の境界にクロダイ・シーバスが寄る理由を科学的に（プランクトン→ベイト→フィッシュイーター）説明。「なぜ昼より夜の方が型が出やすいのか」を理解させることで読者の納得度を上げる。

> 常夜灯については私の意見だと「効果はあまり感じない」があるし、クロダイやシーバスは警戒心があるので逆に釣れにくい印象はある。釣り人はメソッド的にそこへ集まる傾向はあるけど、寄る魚と寄らない魚を意識するべき。日中は大型のクロダイが泳いでる姿を見れるけど、人の姿とか影が入ると逃げる姿をみて考えるべき。

**H3: シーバスナイトゲームの攻略法**  
→ 明暗の「暗側」からルアーを流す基本。アマモ帯際のただ巻き実績。風向き・潮の動きとの組み合わせ。「ここが釣れる時間帯」を具体的に（満潮前後の1時間など）。

> 内浦にアマモは全くないほどじゃないけど、それを意識するほど無いから気にしなくていい。ルアーならベイストリート側がやりやすい。理由としては岸から100mくらい水深がほぼ一定だから。マリーナとか遊覧船が通る場所は一部で水深があるけど、固定レンジで広く探るのに向いているし、ちょっと投げると砂地だからボトム狙いもしやすい。ただ部分的に石とか牡蠣殻が多いので根掛かりリスクはゼロじゃない。

**H3: クロダイナイトの攻略法**  
→ 前打ち・ヘチ釣りで護岸際をなめる。チニングのボトム攻め。夜のクロダイは警戒心が下がるため昼より大型が出やすいことを強調。

> 舘山寺エリアでは水深が一定なことを利点にして電気ウキの夜釣りがおすすめ。ボトムワームではチヌのほかにシーバスやマゴチも混じることもある。ウキ釣りはエサ釣りだけどある程度は放置できるのがメリット。前打ちするなら日中でカニかモエビを使うのがいい。

**H3: ナイトゲームのタックルセット**  
→ TackleCard: シーバス用ロッド・ライン / クロダイ前打ち用タックル / 実績ルアー（ミノー・チニングワーム）。「夜の内浦湾でこれが実績あった」根拠を1行入れる。

**H2: 年間シーズンカレンダー**  
→ 月別で「昼のターゲット / 夜のターゲット」を表形式で。春（クロダイ乗っ込み・昼が熱い）/ 夏（シーバス・夜が本番）/ 秋（秋アジ昼・シーバス夜）/ 冬（厳しいが暖かい日のクロダイ）。

**H2: 内浦湾エリアのポイントを選ぶ**  
→ BlogCard: `kanzanji` / `lakesideway` / `kiga` / `target/seabass` / `target/kurodai`

**H2: ⚠️ 夜釣りの安全・マナー**  
→ ライトマナー（常夜灯の水面を照らさない）/ 足元安全（護岸の際・段差）/ 観光エリアのため騒音注意 / 駐車マナー。「地域に愛される釣り人で」というトーンで締める。

### セクションごとの執筆指示

**H2: なぜ中浜名湖でボートが有効なのか**  
→ ガーデンパーク〜村櫛の護岸は整備されており、陸っぱりで人が多くプレッシャーが高いことを先に認める。ボートを使うと「岸から20〜30m沖のシャロー帯」「村櫛沖のアマモ帯の上」など、陸からはキャストで届くが釣れない（魚が人を嫌って奥に引っ込む）ゾーンに接近できることを書く。「陸から投げて釣るより、静かにアプローチする方が結果が出る」という主張を具体的に。

> ボート釣りのメリットは陸から届かない場所を狙えるし、魚の警戒心がほぼない沖合のシャロー帯を狙えること。中浜名湖エリアは浜名湖内でも水域が広いため、狙い所は逆に絞りにくいけれど、それだけ冒険する楽しみがあるといえる。

**H2: ボートで狙えるターゲットとシーズン**  
→ タコ（夏・底）/ マゴチ（夏秋・底）/ クロダイ（春秋・シャロー）/ シーバス（秋・回遊待ち）。月別表で整理。各魚種で「ボートが特に有利な理由」を1行付ける。

> タコは夏の終わりが近づいていくつれて中浜名湖の航路でも狙い所になる。同時にコウイカも釣れるので状況に応じて狙っていきたい。ここにあげているのはどれも同じタックルで釣れるわけじゃないから、複数タックルを用意して都度交換するか、1魚種に絞って集中するかを選んだほうがいい。

**H3: タコ・マゴチのボトム攻め**  
→ ボートからの真下狙い（バーチカル）がテンヤタコ・ジグヘッドマゴチで最も効率が良い。流れを使った流し釣りの基本。「陸っぱりでは根がかりを恐れてビビるゾーンも、ボートからは垂直に落とせるので根がかりが少ない」という実用的な利点。

> タコもマゴチも平地と航路にできる水深の違いなどささいな変化につく。タコはテンヤ（エギ）でマゴチはルアーだから同じタックルでは釣れないんだけど、例えばタコテンヤをずる引きしている時に「ガツン」とあたってくるとかぐいぐい引っ張られることが多いのであれば、マゴチやヒラメにクロダイなどが多いと判断して、そっちのルアーで攻めるのもいい。

**H3: クロダイのシャロー攻め**  
→ アマモ帯の上を静かに流してチニングワームをゆっくり通す。波音・エンジン音を立てない接近が前提。ボート釣りとチヌトップの相性（弁天島南シャロー等）。

> クロダイはアサリを食べるので、航路ではない平らな砂地に居ることが多い。水温が高い時期がそうであるから1年通して必ず居るわけでもないけど、アマモは小型が隠れる手段にするのであって大型はそんなに隠れない。アマモを通すのではなく、自然に見せるならアマモから出てくる小魚を演出するが正しい。

**H3: シーバスの秋の回遊を狙う**  
→ 秋のベイトフィッシュの群れを追いかけながら移動できるのがボートの強み。ナブラ撃ちの機動力。

> ナブラ発生はそれほど多くないのでそればかり狙っていると疲れてしまう。起きやすいのは夜明けと日没前だから、そのタイミングだけトップウォーターかフローティングミノーを用意しておくといい。

**H2: ボートの調達・利用について**  
→ ボートレンタル情報は変動するため断定せず「事前に最新情報を公式で確認」と誘導。庄内湖ボートエリア（奥浜名湖）との繋がりとして、中浜名湖への連続釣行パターンも提案。ゴムボート・SUPでも入れるエリアとそうでないエリアの区別。

> ゴムボート・SUPは中浜名湖でも北側なら推奨するけど、広いがゆえにあまり沖に出ないようにしたほうがいい。表に近いと潮流がそれなりにあるので、ゴムボートでもエンジンがあると安心ではある。週末や祝日はプレジャーボートなど他の釣り客やレジャーも多いから洋上の移動と停泊は注意すること。航路上は停泊してはいけないと法令にもある。
