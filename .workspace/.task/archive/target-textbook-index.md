## 実行方法

1. 各魚種の **「第4章：一次情報（要入力）」** 欄に自分の釣り経験・失敗談を書く
2. 書いたら「実行指示」ブロックを Claude Code に貼り付けて実行
3. 完了後は「状態」を `完了` に変えて日付を記入

> 第4章の一次情報がない状態で実行しても記事は書けますが、
> 「なぜ釣れないのか」に著者経験が入らず差別化コンテンツになりません。
> 入力できる範囲で構わないので、思い出せるエピソードを箇条書きで。
