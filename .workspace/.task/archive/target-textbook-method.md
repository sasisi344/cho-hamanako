# 魚種別「教科書記事」構成メソッド

**作成日**: 2026-09-04  
**モデルケース**: `target/kurodai/index.mdx`（クロダイ教科書）  
**適用対象**: 全魚種の `target/*/index.mdx`

---

## 1. この手法が解決する問題

既存の魚種別記事群に共通して発生している歪み：

1. **同じ説明の繰り返し** — 生態・シーズン・釣り方の基本説明が複数記事にまたがって重複
2. **アイテム紹介が傍流に偏る** — TackleCardが最初に読まれない深掘り記事にのみ配置
3. **入口が多いのに芯がない** — 「結局どの記事が本編か」が読者に伝わらない

解決策：**`target/*/index.mdx` を中〜上級者向け専門リファレンス（教科書）として全面書き換える**。

---

## 2. 設計方針

### 対象読者の分離

| 読者 | 誘導先 |
|---|---|
| 初心者（1匹目をまだ釣っていない） | `beginner`記事へ序章で即誘導 |
| 中〜上級者（経験者） | 教科書記事（index.mdx）本体 |

### 文体

- **ですます調廃止**。断定・言い切りスタイル（だ・である・〜する）
- 釣り専門誌・フィールドノートに近い文体
- 情報密度が上がり、同じ内容でも20〜30%自然に圧縮される

### 構成原則

- 「通読させる記事」ではなく「必要な章にジャンプできるリファレンス」
- 各章は要約＋`BlogCard`で既存深掘り記事へ誘導
- TackleCardは「実践章」（タックル大全・各釣法）に集中配置。生態章・ポイント章・料理章には置かない

---

## 3. 標準章構成（6〜7章）

```
序章    ｜ この記事の使い方・初心者はbeginner記事へ
第1章   ｜ 生態・環境・近縁種との違い（圧縮・断定）
第2章   ｜ 年間シーズナリティ（表＋水温目安）
第3章   ｜ 釣法選択とポイント逆算（フロー・比較表）
第4章   ｜ なぜ釣れないのか（魚のせい vs 釣り人のせい、一次情報）
第5章   ｜ 実績タックル大全（釣法別TackleCard集約）
第6章   ｜ 時合・潮・状況の原則（＋「◯が釣れたら」シグナル）
終章    ｜ ポイント記事・料理記事への誘導、マナー
```

### 魚種の特性に応じた調整

| 特性 | 調整 |
|---|---|
| バチ抜けなど特殊イベントがある | 第2章シーズン内に専用節を設ける。シリーズ記事はBlogCardで誘導 |
| 複数種をまとめた記事（ヒラメ・マゴチ等） | 第1章で種別の棲み分けを比較表にする |
| ファミリー向け色が強い（ハゼ等） | 初心者誘導を手厚くし、第4章の難易度を下げる |
| ポイントが限定的（メジナ等） | 第3章をポイント論に寄せる |

## 4. 既存記事の処理方針

| 記事タイプ | 処理 |
|---|---|
| `complete-guide`（indexと重複大） | 削除 → 教科書へ301リダイレクト検討 |
| `beginner` | 存続。序章からBlogCard誘導 |
| `tactics` | 存続。第3・5章からBlogCard誘導 |
| `points` | 存続。終章からBlogCard誘導（TackleCardは置かない） |
| `cooking` | 存続。終章からBlogCard誘導 |
| `season/*` | 存続。第2章から「もっと詳しく」BlogCard誘導 |
| 深掘り（ルアー選定・特定エサ等） | 存続。第5章からBlogCard誘導 |
| 明確な重複記事 | 削除候補。内容を教科書に吸収後に判定 |

---

## 5. TackleCard配置基準

| 配置してよい章 | 配置しない章 |
|---|---|
| 第3章（釣法別解説の末尾） | 第1章（生態） |
| 第5章（実績タックル大全） | 第2章（シーズン） |
| 序章・終章を除く実践節 | 終章（ポイント・料理誘導節） |

紹介根拠：**浜名湖での釣行実績・再現性**を明記できるものに限定。汎用的な「とりあえず紹介」は行わない。

---

## 6. 一次情報の収集（第4章の核）

第4章「なぜ釣れないのか」は著者の実体験が不可欠。以下の情報があると記事の差別化になる：

- 「隣は釣れていたのに自分だけ釣れなかった」具体的エピソード
- タックル選択のミスで痛い目を見た経験（竿長・ルアーサイズ・レンジ等）
- 「これを変えたら急に釣れた」改善体験
- 浜名湖固有の注意点（水域の特性・食安全など）
