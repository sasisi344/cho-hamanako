## 3. 原因の仮説（優先度順）

1. **未登録（上記9本）**。「クロール済み・現在未登録」は、Google が内容を見たうえで登録を見送った状態。考えられる理由は、記事間の内容の重なり、サイト全体の評価、更新後の再クロール待ち（§2-1 の比較では、本文量・見出し数・内部リンク数は2グループで差がなかった。差が出たのは最終クロールの新しさ）。`sayori` 2本（`large-sayori-guide`・`april-guide`）、四季2本（`seasonal-patterns-guide`・同名の `guide/theory/` 版を統合済み）など、似た記事が複数あるものは重なりを疑う。**理由の断定には、GSC 画面の「ページのインデックス登録」の個別理由が要る**
2. **旧WP記事の転送が弱い**。旧「10月／11月の浜名湖でおすすめの釣りポイント」（旧URLは 10月 137・11月 344・12月 438 クリック）の新URLへの転送が、HTTP 301 ではなく **HTTP 200 の meta refresh ＋ noindex ページ**になっている（`/2024/10/11月…/` を取得して確認）。Google が転送先へ評価を引き継ぐまで遅く、旧URLが検索結果に残る。実際に GSC では旧URL（`/2024/09/10月の…8選/` ほか）が「浜名湖 秋 釣り」（順位 6.1、表示 18、クリック 3）で出ており、これが **このKWで確認できる唯一の実績**。新URLの `10-month` は未登録なので、受け皿がない
3. **「秋」を含む検索自体が少ない**。12か月で「秋」を含むクエリは全て旧URL経由の 17行だけで、すべて「浜名湖 秋 釣り」。先の四季ガイド調査（`seasonal-guide-rewrite.md`）でも「秋 釣り」は 3クリック。読者は **月（9月・10月・11月）か魚種（カレイ・アオリ・サヨリ）**で探す。タイトルに「秋」を入れても、秋クエリが増えるとは限らない
4. **「秋」の総合記事（ハブ）がない**。「浜名湖 秋 釣り」に正面から答える1本がなく、16本は魚種別・月別に散らばっている
5. サビキ記事の旧URL `/blog/target/aji-saba-sappa/sabiki-guide/` が GSC に残っているが、現在は 404（正規は `/blog/sabiki-guide/`）。転送が要る
