## 2. 収益の流れ（全体の構成）

```
検索「浜名湖 魚釣り」「浜名湖 釣り」
   │
   ├─ ルール記事（今の受け皿・広告あり）── 安全の節: ①子ども用＋②大人用（親子で着る）
   │                                    └ 持ち帰りの節: ③25L or ⑥6L
   │
   └─ トップ（広告なし・送客）
        ├ 季節の釣行案内 → 月別・ポイント記事（カードあり）
        ├ 初めての釣り場3候補 → 新居弁天海釣公園（①）・家族向けハブ（①③）・砂揚げ場（②③、玉網6m）
        ├ 準備（道具なし・初来訪） → ルール記事の安全の節／レンタル記事／`hamanako-complete-tackle-guide`
        └ 遠方から → travel 記事（宿・レンタカー）
```

- **トップには商品カードを置かない**（レイアウトに枠がなく、提案書の役割＝入口と合わない）。その代わり、トップのリンク先を「カードと広告がそろった記事」にする。トップの比較3候補は、H-43 のカードを先に置いた記事から選ぶ
- 同じ商品を全部の記事に置かない。商品は記事の場面で分ける（下の §3）

## 3. ページごとの構成と収益の枠

### 3-1. ルール記事 `guide/beginner/hamanako-fishing-rules-and-manners`（総合KWの受け皿・最優先）

CH-KW-07 の文脈リンクと H-43 のカードを、**1回の書き直しでまとめて行う**（同じファイルを2回触らない）。

| 節 | 今 | 足す・直すこと |
|---|---|---|
| 冒頭 | 規則の記事として始まる | 総合KWに答える2〜3文を足す: 「浜名湖で釣りをする前に知ること＝禁止の場所・漁業権・採ってはいけない魚・安全」。行き先がまだ決まっていない人へ、トップ（釣り場と季節の選び方）への1行リンク |
| 安全のために（389行〜） | ヘッドライト（safety） | **② 大人用ベスト**を置く（筆者の装備、小物が入る、スマホが入る）。子ども連れの段落に「親子でそろえ、まず親が見本として着る」と **① 子ども用**。1節1枚の上限（guide 記事）を守るため、ヘッドライトは夜釣りの段落へ分けるか、①②を「子連れ」の小見出しで分ける。膨張式を子どもに勧めない理由は規約 §2 の文で |
| 採ってはいけない魚介／持ち帰り（143行〜） | なし | 持ち帰りのルールの段落に **③ 25L**（家族・車）。エサ釣り中心の読者向けに ⑥ を選ぶかは、節の文脈で書き手が1つに決める |
| まとめ | 公式情報と看板 | 「次に読む」を3本に絞る: 釣り場の選び方（トップ or `family-car-points`）・毒魚・レンタル |

- 「条例で決まっている」とは書かない（規約 §2）。ライフジャケットの着用義務は法令の正本にないので、「必須」は当サイトの勧めとして書く
- 広告は記事のレイアウトで自動で入る。節を長くしすぎず、安全の節の前後で読み進めてもらえる長さにする（`reader-flow-rules.md`）

### 3-2. トップ `src/pages/index.astro`（CH-KW-04、送客）

提案書 CH-KW-04 の6段の順はそのまま。収益のために次を決める。

| 段 | 収益のための決めごと |
|---|---|
| 季節の釣行案内 | 各季節のリンク先は「カードがある月別・ポイント記事」を優先。カードのない `yearly-fishing-calendar` は2本目以降 |
| 初めての釣り場3候補 | **新居弁天海釣公園**（①を置いた後）、**家族向けハブ `family-car-points`**（①③）、**砂揚げ場**（②③・玉網6m）を第一候補にする。CH-KW-02 で設備・足場の根拠と確認日がそろわない場所は外す |
| 道具なし・初来訪者の準備 | 「持ち物」はルール記事の安全の節（①②）と `hamanako-complete-tackle-guide`（10月にクリックが最も多い記事）へ。レンタル記事へも |
| 出発前の確認 | ルール記事へ（受け皿を強くする内部リンクにもなる） |
| 遠方から | travel 記事（宿・レンタカーのカードがある）へ1行 |

- 計測: トップ→各記事の遷移は GA4 の `pageReferrer × pagePath` で取れる（ch-kw-01 §3）。カードの押下はリンク先の記事で `affiliate_click` を見る

### 3-3. 家族向けハブ `points/family-car-points`（CH-KW-07 と H-43 を同時に）

- 今のカード3枚（クーラー6BL・ちょいハゼセット・サビキセット）。ハブの上限は5枚・1節1枚
- 足す: 「子連れで釣るときの安全」（252行〜）に **① 子ども用**（＋近くに②を「親も着る」として置くかは枚数で判断）。「車を釣り座の横に置ける釣り場」に **③ 25L** を置き、今の `sanka-cooler-6bl` と同じ節なら入れ替える（③は筆者の装備）

### 3-4. 新居弁天海釣公園 `points/omote/araibenten-umiduripark`（トップの第一候補。H-43 の先行分）

- 今3枚（サビキセット・楽天トラベル新居・フィッシュグリップ）でポイント記事の上限。**① を足すには1枚入れ替える**。推奨: 激流の節（249行〜）に①を置き、フィッシュグリップは毒魚の節に残し、楽天トラベルを外すか（旅行は帰りの寄り道の節にあり、クリック実績なし）を指示書で決める
- 本文: 海湖館の貸出は「受付で借りられる（条件は海湖館へ）」まで。筆者は買っておくことを勧める（規約 §2）
