## 結論

**CTR の低下は一部の記事のタイトルではなく、サイト全体で起きている。** 同じ順位帯で比べても、どの帯も前年より 25〜40% 低い。

| 順位帯 | 前年 CTR | 今年 CTR |
|---|---|---|
| 1〜1.9 | 32.7% | 23.3% |
| 2〜2.9 | 19.7% | 15.5% |
| 3〜4.9 | 12.8% | 7.5% |
| 5〜9.9 | 4.7% | 3.5% |
| 10〜 | 3.1% | 3.1% |

（ページ×クエリの行。前年は `#` 付きの行を除く）

原因の候補は2つ。

1. **ページ内リンク（目次へのジャンプリンク）が検索結果から消えた（直せる）**
   - 前年は WordPress の目次（`#index_id0` など）が検索結果にページ内リンクとして出ていた。前年の表示の **66%** はページ内リンクの出たクエリで、同じ順位帯でも CTR が高い（順位3〜4.9: 出た 14.5% ／ 出ない 3.8%。5〜9.9: 7.0% ／ 1.4%）
   - 今年は `#` 付きの URL が **0 件**。今のサイトには目次のコンポーネントがない（`src/` に TOC・headings の実装なし）
   - ただし「出たクエリほど関連度が高い」という偏りもあるので、差の全部がページ内リンクの効果とは言えない
2. **検索結果の画面の変化（直せない）**
   - スマホの CTR が 11.5% → 7.9%（順位 6.4 → 6.2 で同じ）。PC は 8.9% → 9.2%（順位 7.3 → 10.6 と下がったのに CTR は保った）。下がったのはスマホだけ
   - AI による概要などスマホの画面の変化が効いている可能性がある。ここはタイトルでは取り戻せない
