- `｜` で区切った長いタイトル（40〜50字）は、Google が片方だけを選ぶことがある。同じ記事でも、どちらが出るかはクエリによって変わる

## 打ち手 #4 の調べ（2026-11-20、CC）

`1-month` が「浜名湖 1月 釣り」で8位までに出ないのは、**今は1月のクエリがほぼ出ない時期だから**とみる。記事の問題ではない。

- 10/01〜11/17 の GSC で、`1-month` の表示は0（ページ単位でも0）。`12-month` は154表示、`2-month` は2表示。月のクエリは、その月の直前から出始める
- 旧 URL（`/2024/11/1月の浜名湖で狙える！釣り人おすすめポイントと/`）から `/blog/1-month/` への転送は `astro.config.mjs` にある
- 前年の冬、旧1月記事の表示1,983のうち、「浜名湖 1月 釣り」は42だけ。多かったのは「浜名湖 冬 釣り」（150）と「浜名湖 11月 釣り」（49）。冬のクエリは今は `hamanako-winter-fishing` と `12-month` が受ける
- 11/20 の検索で2位に出たカレンダーは、時期外れのクエリに対する Google の代わりの選択と見る
- **確認**: 12/20 ごろに「浜名湖 1月 釣り」をもう一度検索し、`1-month` が出ていなければ順位の問題として調べ直す（schedule-task.md に載せる）
