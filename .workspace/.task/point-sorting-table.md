## 0. 結論

1. **旧URLの転送は機能していないが、機会損失の大きさは「確定」ではなく「要判断」。** 本番は nginx で `.htaccess` の転送は無効、旧WP記事82本（12mで12,424クリック）は404。ただし旧URLへの検索流入は直近3か月で0（Googleが既に外した）で、サイト全体は直近3か月3,024クリックと前3か月（971）から回復している。一方、確実な不具合は**既存の転送24件のうち20件が転送先も404、うち2件は実在記事のURLを上書きして記事が読めない状態**。詳細は §1.1補遺。
2. **方針書が「需要なし」とした地名にも、12か月では実績がある。** 舘山寺145・村櫛漁港112・パークビレッジ68クリックなど。3か月の数字が小さいのは需要がないのではなく、新URLの記事が旧記事ほど検索で取れていないため。転送の有無だけが原因とは言い切れない（§1.1補遺・§1.2）。
3. **「表/中/奥」のうち奥浜名湖だけは検索語として使われている**（12か月 274クリック）。方針書4.1の「区分は検索の入口ではない」は表・中にだけ当てはまる（§1.3）。
4. **魚種×ポイント・月別が最大の入口。** 旧キス記事だけで1,276クリック。方針書の3区分（地区束ね／条件ハブ／地名単独）には魚種軸がない（§1.4）。
5. 仕分けを **7区分**（A〜H）に拡張した。53本の内訳は A=14, B=9, C=13, D=5, E=7, F=3、既存の束ね記事H=2（§2〜§4）。
6. **現在の第1波15本のうち、動機づけ改修の費用対効果が低い記事が多い。** ボート系5本・要判断1本が含まれる一方、A区分の舘山寺・瀬戸水道は転送復旧が先（§6）。
7. 現行3か月で30クリック以上ある `konankoukou` / `megaura` / `photonics-under` は、**被リンクが各1本しかない**。動機づけ前に導線強化で伸ばせる（§6）。

### 1.1補遺 機会損失はあるか（2026-10-05 追加確認）

**サイト全体の水準**

| 期間 | クリック |
|---|---:|
| 2025年7〜9月（旧サイト） | 約6,200（2,000+2,393+1,825） |
| 2026年4〜6月（移行直後） | 971 |
| 2026年7〜9月（直近3か月） | 3,024 |

「過去より増えている」は**移行直後の底からの回復**としては正しい。2025年同期との比では約-51%。

**旧URLに来ている流入はあるか**

- GSC: 旧WP形式URLの表示は直近3か月で**0**、その前の3か月で19クリック/626表示。Googleは旧URLを既にインデックスから外しており、「今旧URLに来ている検索流入を取りこぼしている」状態ではない。
- GA4: 404ページにGA4タグがない（素の「404 File Not Found」）ため、旧URLに来て離脱した訪問（被リンク・SNS・ブックマーク由来）は**計測できない**。「GA4に出ないから影響なし」とは言えない。サーバーのアクセスログは未確認。

**転送がなかった旧地名記事の回復度（19組、四半期換算 vs 現行3か月）**

- 全体: クリック 1,403 → 396（維持率28%）、表示 13,429 → 5,783（43%）
- 回復している: 渚園・中之島 800→144（旧四半期200に対し72%）、新居弁天海釣公園（148%）、女河浦（205%）、湖南高校（73%）
- 回復していない: 猪鼻湖 1,168→18、舘山寺 628→0、都田川 626→21、村櫛漁港 529→3、瀬戸水道 261→0、パークビレッジ 105→0
- 転送のない19組の中で回復度に大差があるため、**転送の有無だけでは説明できない**（新URLの記事自体の強さ・公開時期・競合の影響が混ざる）。季節差（旧は年間÷4、現行は7〜9月）も含む概算。
- 技術面の欠陥はない: 53本とも本番で200、noindexなし、canonical正常、サイトマップ掲載済み。

**確実な不具合（判断不要）: 既存の転送24件のうち20件が不具合**

- 転送先がディレクトリ構造のパスで、実URLは `slug:` フロントマター由来のため404（18件）。
- **2件は実在記事のURLそのものを転送元にしている**（`/blog/anazuri/`、`/blog/hamana-depth-map-guide/`）。記事本体の代わりに転送スタブが出力され、存在しないパスへ飛ばされるため、**この2記事は現在読めない**。ルール2行の削除で復旧する。
- 先の報告で「正しい転送先」とした `/blog/anazuri/` と `/blog/hamana-depth-map-guide/` は、上記の理由で誤りだった（200でも転送スタブだった）。
- 全件の修正内容は [redirect-targets.md](redirect-targets.md) §1。

**判断の整理**

- 既存20件の修正は、設定1か所の修正で済み、副作用の懸念もない。
- 旧地名記事82本の転送追加は、効果が確認できない可能性が高い（Googleが外してから約半年）が、被リンクや保存済みリンクがあれば拾える。コストは小さく、害はない。優先度は上記11件の修正より下。
- 旧URLへの被リンクの有無は未確認（外部ツールが必要）。

## 2. 仕分け区分の定義

方針書4.2の3区分を、データに合わせて7区分に拡張した。

| 区分 | 意味 | 記事側の対応 | 導線 |
|---|---|---|---|
| **A 地名単独（維持／復旧）** | 地名で検索される実績がある | 地名をタイトルに維持。内輪語を条件・シーン訴求に置換。旧URLがあれば転送復旧 | 魚種ハブ・条件ハブ・地区束ねから受ける |
| **B 地名単独（弱）** | 旧URL実績はあるが地名クエリが弱い | 地名は残すが条件（車・ウェーディング等）を前面に | 同上 |
| **C 地区束ね配下** | 地名では検索されない。需要のある地区に属する | 単独で地名KWを狙わず、地区の代表記事に節として寄せる／代表記事から誘導 | 地区代表記事 |
| **D 条件ハブ配下** | 地名需要なし。条件（車横付け・ウェーディング・ファミリー）で入る | 条件ハブを入口に。記事側は対象ユーザーの条件を明示 | 条件ハブ |
| **E ボート系ハブ配下** | ボート・渡船が必須 | 個別改修より受け皿の整備を優先。`rental-boat-guide` 等から誘導 | ボートハブ |
| **F 要判断** | 検索実績なし・被リンク少・用途が弱い | 統合か低優先。着手前に要否を決める | なし |
| **H 既存の束ね記事** | ハブ・索引として既に存在 | 個別記事の整備後に導線を更新 | — |

**判定の目安**（機械的に当てはめ、例外は表の備考に記載）:

- A: 地名Q 12mが20クリック以上（魚種×地名のクエリを除く）／現行3mが30クリック以上／旧URLが200クリック以上
- B: 上に当たらず、旧URL60クリック以上／現行3mが10〜29クリック／地名Q 12mが5〜19クリック
- C・D: 上に当たらず、地区の束ねまたは条件ハブに属する
- 共有されていた旧記事（猪鼻湖・村櫛漁港＋ガーデンパーク・乙女園＋サクラマル・気賀＋寸座）の旧クリックは、代表1本にのみ帰属させて判定した
- 例外: `shinkawa-kakou`（地名Qの中身が「ハゼ×新川」の魚種クエリ）、`bentenjimakaihinkouen`（「弁天島」は地区名）、`sakujyoseki`（現行17クリックは猪鼻湖総称のクエリで取れている可能性）、`hamayu-ohashi`（クエリが通行料金系）、`imagiremaisakatei`（クエリが禁止ルール系だが地名としてA）
