# マッチング率分析：採用タックル vs 市場推奨タックル

**作成日**: 2026-09-24
**元データ**: [current-tackle-inventory.md](current-tackle-inventory.md)（当サイト採用）× [market-research.md](market-research.md)（Web検索によるメディア・実釣者の推奨）

## 判定基準

| 記号 | 意味 |
|---|---|
| ◎ 完全一致 | 商品名・型番まで市場推奨と一致 |
| ○ ブランド/シリーズ一致 | 同一ブランド・同一製品ライン（型番・サイズ違い） |
| △ タイプ一致 | ブランドは異なるが、製品タイプ・スペック（号数・重量・仕様）レベルで市場の推奨傾向と一致 |
| ✕ 乖離・ギャップ | 市場推奨と異なる、または該当する採用アイテムがない |

**注意**: これは「今使っている商品が正しいか」の答え合わせではない。市場と違う選択をすることが即NGではなく、「地元ゾーン（このポイントに特化したチョイス）」として意図的に外している場合はむしろ強み。ここでは事実としての一致度を可視化することが目的。

## 優先対応候補（マッチング率向上インパクトが大きい順）

1. **エギング（ダイワ→シマノ/ジャッカル比較の検証）**: ブランド不一致が明確。`eging`カテゴリのTackleCard選定を見直すか、両ブランド併記にするか判断が必要
2. **ハゼクラの「はぜむしSS」未採用**: 市場代表格が抜けている。`affiliates/haze/`への追加を検討
3. **アジ・サバ・サッパの「トリックサビキ」商品不在**: 記事内容（`sabiki-set-comparison`）とアフィリエイト商品のズレ。記事とTackleCardの整合を取る
4. **メバリング/アジングワームのブランド差**: テトラワークス・一誠等、より市場認知度の高いワームへの入れ替えを検討

## 今回のリサーチの限界（次回への引き継ぎ）

- WebSearchの要約経由のため、一次情報（各記事本文）の完全な精読はできていない。上記の優先対応候補に着手する際は、該当ページを個別にWebFetchで再確認すること
- 個人ブログ（hama-angler・hamanavi-blog等）の内容は執筆者の主観が強く、「メディアの総意」とは言い切れない。複数ソースでの裏取りが望ましい
- YouTube・SNS（Instagram/X）上の実釣タックル紹介は未調査。特にシーバス・チニングは動画コンテンツでのタックル紹介が多いジャンルのため、追加リサーチの価値が高い
