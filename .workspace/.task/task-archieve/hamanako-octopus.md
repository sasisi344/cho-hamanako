# 浜名湖のタコ釣りに関するリサーチデータ格納

## 概要
「浜名湖 タコ釣り」は浜名湖の魚釣りにおけるビッグワード。この情報をフォローするためにも、浜名湖で出来るタコ釣りについて網羅的な記事を作成するため、リサーチから充実した内容を作成する。

## リサーチ内容と対象

1. メインKWとして「浜名湖」「タコ釣り」「時期」「ポイント」はマストなKW。これらを軸にサジェストKWを作成して記事に反映する。
2. 作成する記事はすでにあるものを利用する。methodかtheoryにタコ釣りの記事があると思うので、なるべく1記事に統合して充実した内容に更新したい。
3. タコ釣りシーズンについて、浜名湖における「平年」を断定したい。私の体感と知識では”釣りやすさ”を考慮すると「4~9月」がベストと考えられる。浜名湖における釣果をリサーチ、2000年から2020年、2020年から2025年を対象にしたリサーチをして、「何月にタコが釣れたという報告が多いか？」をヒートマップ的なグラフにして、学術論文スタイルでタコが釣れやすい時期を特定するアプローチをする。
4. (3)の補足として。もちろんその他でも釣れる時期はあるが、今切口のテトラで穴釣りをしていると可能性はあるが専用のテンヤじゃないと釣り上げるのは難しいこと。
5. ポイント情報としては、陸地（陸っぱり）からの釣り、ボートからの釣りで分けられる。春先は産まれた当歳が多く陸からでも釣れやすいがサイズが小さく、夏から秋にかけては深場に移動しやすいのでボートが有利、みたいな構図を特定したい。
6. 浜名湖のタコ釣りで実績のあるタコエギ・タコングのアイテムをリサーチ。
7. 浜名湖のタコ釣りで実績のある道具、釣り竿・リールなどのタックル一式をリサーチ。

> [!forAI]
> ある程度は同一の処理中に答えを見いだせるはずなので、効率的な並列エージェントのResearch設計を先に作成すること。

### Research内容の補助
1~7項目を作成したが、なにかまだ足りないと感じている。補足を想像できるなら追加しておいてほしい。

## Research設計（並列エージェント）

> 独立して実行可能な4チームで並列処理し、最後に統合する。除外ドメインは全エージェント共通で適用。

### Agent-A: 釣果シーズンデータ（Web検索）
**担当**: アイテム3 — 月別釣果ヒートマップ用データ収集

```
優先調査先:
1. イシグロ釣果情報 — 「浜名湖 タコ」で絞り込み、月別投稿数を記録
   （2020-2025年を中心に、可能なら2010年代も遡る）
2. X/旧Twitter — 「浜名湖 タコ 釣れた」のタイムライン。月別の盛り上がりを確認
3. 個人ブログ — 釣果記録系ブログの浜名湖タコ記事の日付から月分布を補完
4. 気象庁 — 浜名湖（舞阪）の月別平均水温データ（タコ活性との相関軸）
5. J-STAGE/CiNii — マダコ産卵期・着底期（"Octopus vulgaris" + "Japan" + "season"）

除外:
- cho-hamanako.info は参照しない

出力形式:
- 月別釣果報告数の相対的な分布（1月〜12月）
- 水温との相関メモ
- 引用できる出典URL
- 「イシグロ釣果」で確認できた最頻月のスクリーンショット相当のメモ
```

### Agent-B: タックル・アイテムリサーチ（Web検索）
**担当**: アイテム6・7 — タコエギ/タコング/タックル一式

```
優先調査先:
1. イシグロ店舗ブログ/公式 — スタッフが実際に使っているタコ向けアイテム
2. メーカー公式（ダイワ・シマノ・ヤマシタ・エコギア・バレーヒル等）
3. Amazon/楽天 タコエギ 売れ筋ランキング + レビュー
4. YouTube 「浜名湖 タコ釣り」— 動画内で映り込むタックルのブランド確認
5. 個人ブログ — 浜名湖タコ実績ルアーの言及

除外:
- cho-hamanako.info は参照しない

出力形式:
- タコエギ/タコング: 商品名・メーカー・重さ・カラー・価格帯（実績コメント付き）
- ロッド: 長さ・硬さ・PEライン適合
- リール: 番手・ドラグ力
- TackleCard用データ（ASIN or 商品名）
```

### Agent-C: ポイント・行動パターンリサーチ（Web検索）
**担当**: アイテム4・5 — 陸っぱり/ボート/今切口情報

```
優先調査先:
1. イシグロ釣果情報 — 「タコ」+「浜名湖」で場所名が言及されているもの（砂揚場・新居海釣公園等）
2. 個人ブログ — 「今切口 タコ」「浜名湖 タコ テトラ」などでのポイント言及
3. X — 「今切口 タコ」「浜名湖 ボート タコ」でのリアル報告
4. 遊漁船情報 — 浜名湖エリアのボート屋（幸丸・三共丸等）公式の釣果情報

除外:
- cho-hamanako.info は参照しない

調査項目:
- 今切口テトラ穴釣り — テンヤ必須の理由・仕掛け詳細
- 春（4-5月）: 当歳ダコの陸っぱり実績ポイント
- 夏〜秋（7-10月）: 深場移動パターン・ボートアドバンテージ
- 潮回り（大潮/中潮/小潮）とタコ活性の相関報告

出力形式:
- 陸っぱり実績ポイントリスト（場所名・水深・底質）
- ボートポイント（水深・移動パターン）
- 今切口テトラの詳細
```
