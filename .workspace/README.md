# ワークスペースの資料案内

更新日：2026-11-12

記事の制作資料・調査・作業記録への入口です。

## 目的別の参照先

| 探すもの | 参照先 | 内容 |
|---|---|---|
| 完了した記事の下書き・アウトライン | [archive/README.md](archive/README.md) | 冬旅3記事の制作資料を記事名別に保管。本番記事との対応も記載 |
| 制作中の下書き | [_draft/](_draft/) | 別件の検討稿。冬旅3記事の整理済み8ファイルはarchiveへ移動 |
| ブレスト・調査メモ | [_inbox/](_inbox/) | 冬旅の構想・類似記事調査・キャッチコピーなど |
| 作業結果・検証記録 | [codex/reports/](codex/reports/) | 完成・移行・ビルド・文体調整の報告 |
| 釣り場・内部リンク等のデータ索引 | [.data-set/.index/manifest.json](.data-set/.index/manifest.json) | 必要なデータセットの参照先 |
| 本番の記事本文 | [src/content/blog/](../src/content/blog/) | 現在の本文・frontmatterの正本 |

## 人間・AIが読むときの順序

1. 制作履歴を探す場合は[アーカイブ一覧](archive/README.md)から記事名・状態を確認する。
2. 現在の記事内容や掲載情報は、対応する本番MDXを確認する。
3. 企画の意図や選定理由が必要なときに、アーカイブのアウトライン・下書き・関連調査を読む。
4. 古い報告書のパスが見つからない場合は、[旧パスと新パスの対応](archive/index.json)で移動先を確認する。

このREADMEは資料の配置案内です。

記事の執筆・変更に関する規約は[サイトのCLAUDE.md](../CLAUDE.md)と、そこで指定された正本を参照してください。
