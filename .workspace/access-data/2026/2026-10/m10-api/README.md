## 3. 読み取れること・次に見ること

1. **検索は全体に底上げ**（クリック +43%、表示 +39%）。ルール・マナー、キビレ料理、車横付けポイントなど、順位が 1〜4 位上がった記事が目立つ。どの記事に手を入れた効果かは、変更日の記録と突き合わせて確認する
2. **検索流入の 89% が Organic Search**。AI Assistant 経由が 39 セッションあり、9月の 60（旧計測）と同水準。AI 経由を育てるなら別途追う価値がある
3. `araibenten-live-camera` は流入もアフィリエイトクリックも多い（クリック 100）が、検索需要は減少傾向。季節要因かどうかは11月の数字で確認する
4. `hamanako-depth-map` は9月は表示ゼロ、10月に 30 クリック。新規の当たり記事として観察を続ける
5. `(not set)` の入口 60 セッションは品質が低く、計測のノイズとして扱う。10月のエンゲージメント集計から外して見るか、原因を確認する
6. 効果測定の項目（`schedule-task.md`）は、この月次の数字と突き合わせて更新する。変更日のある記事は、変更日の前後を同じ日数で比べること
