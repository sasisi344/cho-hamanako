## 月別のページ・クエリ（`api/`、2026-10-29 に Claude が API で取得）

- `api/yoy-ページ-YYYY-MM.csv`・`api/yoy-クエリ-YYYY-MM.csv`（2025-11・2025-12・2026-01 の6ファイル）

- 列は英語（`page`/`query`, `clicks`, `impressions`, `ctr_pct`, `position`）。CTR は % の数字、順位は小数1桁
