- 指示書の「対象」の表にないファイルは変えない。`astro.config.mjs`・`src/content/affiliates/` を変えない（新しいカード ID を作らない。足りない商品は報告書に「こういう商品があれば置ける」と書く）

- slug を変えない。タイトルは、指示書に「変える」と書いた記事だけ変える（変えたいときは案を報告書に書く）

- 商品の価格・割引率・セールの開催日を書かない。「最強」「必ず」「最安」を書かない。yaml にない仕様を書かない
- 見出しを増やすためだけの節を作らない。答えを記事の後ろへ回さない
- コミット・push・ブランチ操作をしない。検索エンジンへの登録の依頼をしない
