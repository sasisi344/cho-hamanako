浜名湖のヒラメとマゴチは、表浜名湖から中浜名湖の全域に生息していると考えていい。

ただし「同じ場所、同じ釣り方でどちらも釣れる」とは限らない。ヒラメは春の産卵シーズンが最大のチャンスで、ボートから活き餌を使った泳がせ釣りが定番だ。夏はヒラメが産卵後で活性が落ちる一方、マゴチの活性が上がる。ルアーでどちらも狙えるが、ルアーへの反応はマゴチの方が良い傾向がある。

専門で大型を狙うなら陸っぱりより、ボートから航路付近を狙う方が現実的だ。

この記事は入門段階を経てヒラメ・マゴチをより深く攻略したい経験者向けの専門リファレンスだ。

## 第1章｜生態・ヒラメとマゴチの棲み分け

| 項目 | ヒラメ | マゴチ |
|---|---|---|
| 分類 | カレイ目ヒラメ科 | スズキ目コチ科 |
| 体の向き | 左向きに横たわる（左利き） | 腹ばい型（体が扁平） |
| 主食 | 小魚（イワシ・アジ等） | 小魚・エビ・カニ |
| 好む場所 | 砂底・砂礫底。岸寄り〜中深場 | 砂底。やや浅場（2〜10m） |
| 捕食スタイル | 底から飛び上がって小魚を捕食 | 底をゆっくり泳ぐ底べったり型 |
| 釣れやすい時期 | 春（産卵）・秋〜冬 | 夏（6〜9月）が全盛 |
| ルアーへの反応 | 出るが乗せにくい場合が多い | 比較的ルアーに反応しやすい |
| 最大サイズ | 80cm超（大型は稀） | 60cm前後 |

<strong>浜名湖での分布</strong>：

ヒラメは今切口〜弁天島周辺の砂底帯・航路付近。マゴチは表浜名湖全域の砂底に広く分布する。どちらも底を泳ぐ魚だが、ヒラメは小魚の群れを追って中層にも出てくる機動力があるのに対し、マゴチは底から離れない傾向が強い。

## 第2章｜年間シーズナリティ

| 時期 | ヒラメ | マゴチ |
|---|---|---|
| 3〜5月（春） | <strong>最盛期</strong>（産卵接岸・活性高） | 接岸スタート。サイズが上がり始める |
| 6〜8月（夏） | 産卵後。痩せた個体が多く外れやすい | <strong>最盛期</strong>（活性・サイズともに最高） |
| 9〜11月（秋） | 体力回復・活性が戻る | 徐々に活性が落ち始める |
| 12〜2月（冬） | 深場移行。大型が残るが釣りにくい | 深場越冬。実質オフシーズン |

「秋のヒラメ」も実績があるが、浜名湖での安定した釣果という意味では春の産卵期が最もわかりやすい。11月前後に両種が重なるシーズンが最も効率よく狙える時期だ。

### 泳がせ釣り（ヒラメ・マゴチ共通）

活き餌（小アジ・小イワシ・キス）を使った泳がせ釣りは、ヒラメ・マゴチ両方に最も実績のある釣り方だ。

特に春のボート釣りでは航路周辺の水深8〜15mを狙い、活き餌をゆっくり底付近で泳がせることが基本だ。陸っぱりからも堤防・護岸沿いで泳がせができるが、届く範囲が限られる。

## 第4章｜なぜ釣れないのか

### アワセのタイミング（ヒラメ最多の失敗）

ヒラメは「噛みついてから飲み込む」2段階の捕食をする。「コツコツ」という前当たりでアワセると針に乗らず、エサだけ取られる。

重みが乗ってから（完全に食い込んでから）アワセることが基本だ。「待って待って、確実に乗ってから」という我慢が必要で、経験値が要求される部分だ。マゴチに比べてヒラメのフッキング成功率が低い理由はここにある。

### 活き餌の管理

泳がせ釣りで最も重要なのは活き餌の状態だ。弱った餌は動かなくなり、ヒラメ・マゴチの追いが悪くなる。

頻繁（15〜20分に1回）に確認して弱っていたら交換するか、軽く引いて回遊させることが釣果を維持するコツだ。特に夏の水温が高い時期は餌の弱りが早いため、小型のバケツに酸素（エアポンプ）をセットして活かしておく。

### レンジの問題

ヒラメ・マゴチとも「底から1〜2m以内」にいることが多い。特にマゴチは底べったりのため、ルアーやエサが底から離れすぎると反応しない。

ルアーが「たまに底を叩く」感触があるくらいのレンジをキープすることが重要で、浮き上がりすぎると反応が極端に落ちる。

### 「夏のヒラメ」は狙いにくい

夏（7〜8月）のヒラメは産卵後で痩せており、体力回復のために積極的に食わない個体が多い。釣れないわけではないが、釣果が安定しない時期だ。夏にヒラメを狙うより、同じ場所でマゴチを狙う方が効率が良い。

## 第6章｜時合・潮・ベイトの原則

### 朝マズメと夕マズメ

ヒラメ・マゴチとも光量変化のタイミング（夜明け〜日の出後2時間、日没前後2時間）に活性が上がる。特に朝マズメは両種ともに捕食スイッチが入りやすく、最もルアーへの反応が出やすい時間帯だ。

### 潮とベイトフィッシュ

ヒラメ・マゴチはベイトフィッシュ（小魚の群れ）を追う。潮が動くと小魚の群れが流れてくるため、潮が動く時間帯（上げ・下げとも流れている時）が時合いになりやすい。

表浜名湖では上げ潮で外洋から小魚が入り込みやすく、今切口付近でベイトフィッシュを確認できる日はヒラメ・マゴチの活性が高い。

### 「砂煙」を探す

ヒラメ・マゴチが砂底に潜っていると、砂が巻き上がって「砂煙」が起きる場合がある。ボート釣りで水面から砂煙が見えるポイントは底に魚がいるサインだ。透明度の高い日に確認できる。

## 釣ったあとの楽しみ方

ヒラメは刺身・鍋が最高で、特に「縁側」（ひれ周りの身）は脂がのった最上部位だ。マゴチは刺身・天ぷら・鍋いずれも美味く、皮の旨みを活かした焼き物も定番だ。

## マナー・安全

ヒラメの歯は非常に鋭い。取り込む際には素手で口を触らず、魚つかみを使うか、エラから手を入れて保持する。マゴチは歯が細かく怪我をしやすいため同様に注意が必要だ。

ボート釣りでの活き餌使用は、釣り場でキスやアジを釣って使う場合が多い。その場合、漁業権や漁業規制のある場所での採取は避ける。
