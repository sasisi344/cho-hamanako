サヨリ釣りは「専用の仕掛けが必要」という入門ハードルがある。それさえ超えれば、群れが来た時の数釣りの楽しさはシンプルで中毒性が高い。

群れが回っているかどうかが釣果のほぼすべてで、夏から秋にかけて「釣れだした」という情報が出回ると定番ポイントに自然と人が集まる。その情報を待ってから釣行しても遅くない。フットワーク重視で釣れているタイミングを狙いに行く戦略が最も効率がいい。

難点はアミエビ（コマセ）を毎回用意する手間だ。チューブ入りの保存しやすいアミエビ代替品を活用したり、針にカマス用のスキン付き針を使ったりすることで準備のコストを下げられる。

この記事は入門段階を経てサヨリ釣りの釣果を安定させたい経験者向けの専門リファレンスだ。

## 結論｜浜名湖のサヨリは「いつ・どこで・何で」釣れる？

先に結論を整理しておく。

- <strong>いつ</strong>：夏〜秋が本番で、<strong>メインは10月</strong>。数釣りは8〜10月、10月以降は30cm級の釣果報告も出る。サイズ狙いは冬だが、陸っぱりからは難しいのでボート推奨
- <strong>どこで</strong>：外海から今切口を通って入ってくる回遊魚なので、表浜名湖（今切口〜弁天島周辺）が中心。潮通しのいい護岸・港周りに群れが回る
- <strong>何で</strong>：コマセを撒いて群れを待つ<strong>ウキカゴ</strong>、遠投してゆっくり巻く<strong>浦安釣法</strong>の2系統。沖の大型を狙うなら後者
- <strong>釣果を分けるもの</strong>：腕より先に「群れが入っているか」。釣れ始めの情報を待ってから動くのが効率的

詳しい根拠は以降の章で解説する。

## 第1章｜生態・浜名湖でのサヨリ

サヨリ（学名：<em>Hyporhamphus sajori</em>）はダツ目サヨリ科。

細長い体型で下顎が長く突き出しているのが最大の特徴。表層（水面直下〜50cm）を泳ぐ表層特化型の回遊魚で、群れで行動する。

### 浜名湖での分布

外洋（遠州灘）から今切口を通じて浜名湖内に入り込む回遊魚。夏〜秋に接岸し、表浜名湖の護岸・港周辺に群れで回遊する。奥浜名湖まで入り込むことはほぼなく、今切口〜弁天島付近が主な釣り場になる。

### 食性

植物性プランクトン・小型の甲殻類・アミエビを好む。フカセのコマセ（アミエビ）への反応が強く、コマセを撒くことで群れを手前に引き寄せることができる。

### サヨリの性質まとめ（釣り方に直結するポイント）

| 性質 | 内容 | 釣りへの影響 |
|---|---|---|
| 泳層 | 水面直下〜50cmの表層 | ウキ下は浅く（1ヒロ以上は深すぎる） |
| 行動 | 数百〜数千匹の群れで回遊 | 群れが入れば入れ食い、入らなければ全く釣れない |
| 水温 | 12〜20℃で沿岸の浅場へ接岸 | 夏〜秋に岸寄りのチャンスが来る |
| 警戒心 | 強い。大型ほど岸壁の近くを避ける | 仕掛けは静かに置く。大型は沖の潮目を遠投で狙う |
| 動き | 潮と風に乗って移動する | 上げ潮の動き出しと、風下への流しが時合のカギ |
| 食性 | アミエビなどのプランクトン類を好む | コマセで足止めできる |

### 「待つ釣り」と「攻める釣り」の違い（釣法比較）

浜名湖のサヨリ釣りは、大きく<strong>ウキカゴ（待つ釣り）</strong>と<strong>浦安釣法（攻める釣り）</strong>の2系統に分けて考えると整理しやすい。

| 項目 | ウキカゴ（待つ釣り） | 浦安釣法（攻める釣り） |
|---|---|---|
| 基本の動き | 投げ込んでコマセを撒き、群れが回ってくるのを待つ | 遠投して、ゆっくり巻きながら群れを探す・追わせる |
| 向く状況 | 足元〜近距離に群れが入っている日 | 群れが沖にいる日、群れが薄い日、大型狙い |
| 巻き方 | 基本は止めて待つ（コマセを振り出す） | デッドスロー。巻いているか分からないくらいが目安 |
| アタリ後 | 通常の合わせ | 合わせずに巻き続けて追い食いを待つ（掛けた後もテンションを緩めない） |
| 道具の特徴 | 一般的なウキカゴ仕掛け | 引き釣り用のウキカゴ（SS-II EXなど）＋遠投向けのタックル |
| 強み | 手軽で入門しやすい | 沖の大型に届く。手返しが速い |

浦安釣法の考え方・タックル構成は、考案元の工房浦安の解説（[サヨリを効率的に仕留める「浦安釣法」の釣り方](https://koubou-urayasu.com/%E3%82%B5%E3%83%A8%E3%83%AA%E3%82%92%E5%8A%B9%E7%8E%87%E7%9A%84%E3%81%AB%E4%BB%95%E7%95%99%E3%82%81%E3%82%8B%E3%80%8C%E6%B5%A6%E5%AE%89%E9%87%A3%E6%B3%95%E3%80%8D%E3%81%AE%E9%87%A3%E3%82%8A%E6%96%B9/)）が詳しい。それによると、遠投のために道糸の先に力糸（PE2〜3号を8〜10m）をつなぎ、警戒心の強いサヨリ対策として、ウキカゴから針までの先糸を長めに取るのが特徴だ。コマセは、集魚力の高いブロック状と、持ち運びに便利なチューブ状を使い分けられる。

### ウキカゴ釣り

コマセカゴ付きのウキ仕掛けで、コマセ（アミエビ）を撒きながら針に刺したアミエビをサヨリに食わせる。

コマセは上カゴに詰め、仕掛けを軽く振ってコマセを放出する。コマセが撒かれた中に針を漂わせる。シンプルで最も広く使われているサヨリの釣り方だ。

## 第4章｜なぜ釣れないのか

### 群れがいない（根本的な問題）

最大の原因は「群れが来ていない日に釣行している」ことだ。

サヨリはタイミング次第で「入れ食い」か「全くダメ」の2択になりやすい。「周りで釣れている」情報がないままポイントに来ても釣れない日がある。事前の情報確認が前提だ。

### コマセが切れている

サヨリはコマセ（アミエビ）に群れが寄ってくる。コマセが切れると群れが散る。コマセを絶やさず撒き続けることが群れを手前にキープするための必須条件だ。

コマセに「毎回アミエビを購入するのが面倒」という場合は、チューブ入りアミエビ（保存が効く）や、アミエビ不要で使える針（スキン付きカマス針）を試すことで準備コストを下げられる。

### 仕掛け投入時に群れを崩す

サヨリは警戒心が強く、仕掛けを素早く投げ込むと群れが散ることがある。コマセを撒いて群れが寄ってきたら、仕掛けはゆっくり・静かに水面に置くように投入する。

### タナが深い

サヨリは水面直下（30〜50cm）を泳ぐ。ウキ下が深すぎると（1ヒロ以上）仕掛けがサヨリの泳ぐ層より下になり、食わない。浅いタナに設定することが基本だ。

## 第6章｜時合・群れの見つけ方の原則

### 群れのサインを見逃さない

サヨリの群れが入ると、以下のサインが出る。

- 水面近くを細長い魚影が大量に泳いでいる（見える場合もある）
- コマセを撒くとアミエビに小さな波紋が多数起きる
- 隣の釣り人が連続してサヨリを掛けている

これらのサインを確認したら仕掛けを速やかに入れる。群れは風・潮流で移動するため、群れの動きを予測しながら投入位置を調整する。

### 風と潮流の活用

サヨリは風上から風下に向かって泳ぐ傾向がある。向かい風のポイントより、追い風になる方向に立ち、仕掛けを風下に流すと群れに追いつきやすい。

### 人だかりに注目

ベテランの釣り人が集まっているポイントは、サヨリが釣れている証拠だ。釣り場全体の状況を観察してから入るポイントを選ぶことも重要な判断だ。

## マナー

定番ポイントは混雑しやすい。隣の釣り人のコマセの流れを妨害しないよう、投入位置への配慮が必要だ。

仕掛けが隣の釣り人に絡まった場合は落ち着いて丁寧に解く。釣れていないからといって隣に近づきすぎることはトラブルの元だ。
